# UAS-Pemograman-Mobile-2

"
Project yang saya buat adalah aplikasi E-Inventory yang berfungsi untuk membantu pengelolaan stok barang secara digital. Saat aplikasi dijalankan, pengguna akan melihat Splash Screen sebagai tampilan awal sebelum masuk ke sistem.

Selanjutnya, pengguna dapat melakukan Register untuk membuat akun atau Login jika sudah terdaftar. Setelah berhasil masuk, pengguna akan diarahkan ke halaman Dashboard yang menampilkan ringkasan informasi stok barang secara umum.

Aplikasi ini juga memiliki fitur Stock Report untuk melihat laporan stok secara detail, serta Stock History yang mencatat riwayat keluar dan masuknya barang. Selain itu, terdapat fitur Profile yang digunakan untuk melihat informasi akun pengguna.
"
